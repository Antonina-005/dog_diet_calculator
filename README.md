# Ветеринарный калькулятор суточного рациона собак

Интерактивное приложение на Python (MVP версия 1.0) для расчета индивидуальной суточной нормы кормления при смешанном рационе (сухой корм утром, влажный корм вечером).

## Функционал и особенности
- **Расчет по ветеринарным формулам**: вычисление базовой потребности в энергии (RER) на основе метаболического веса собаки ($70 \times \text{Вес}^{0.75}$).
- **Динамическая стабилизация веса**: автоматическая корректировка калорийности (коэффициент MER) при избыточном весе, худобе или нормальном состоянии.
- **Учет пола и возраста**: адаптация нормы питания для щенков, взрослых и пожилых собак с учетом особенностей метаболизма кобелей и сук.
- **Индивидуальные рекомендации**: автоматический расчет суточной нормы чистой воды и выдача адаптивных советов по уходу в зависимости от состояния здоровья.
- **Интерактивная валидация**: надежная защита от некорректного ввода данных (букв, отрицательных чисел).

## Структура проекта
- `main.py` — основной исполняемый код программы.
- `.gitignore` — конфигурационный файл для сокрытия папки виртуального окружения (`venv/`).
- `requirements.txt` — файл фиксации зависимостей проекта.

## Инструкция по запуску
1. Скачайте файлы проекта в отдельную папку.
2. Активируйте виртуальное окружение в терминале: `source venv/bin/activate`
3. Запустите калькулятор рациона: `python main.py`
